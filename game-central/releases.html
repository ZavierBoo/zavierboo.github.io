How to use the calendar

Start with the platform column so you can focus on games for the hardware you own. Then compare genres: an action RPG may suit players who enjoy combat and character progression, while a racing game emphasizes handling, timing, and competition.

Before buying a real upcoming game, check the publisher’s website for its latest release date, supported platforms, and system requirements. Launch schedules can change, and a PC or console label does not guarantee support for every device.
